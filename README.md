# rairurairu.github.io

Personal site of TSANG Cheuk Nam (Tony Tsang): https://rairurairu.github.io

Plain static HTML and one stylesheet; no build step. Content is drawn from the CV workspace
(`D:\cvbuilding`: claim ledger and project dossiers) and follows its style guide.
The CV PDF in `cv/` is built from `applications/_web-cv` there.

To use a custom domain later: add a `CNAME` file with the domain, point its DNS at GitHub Pages,
and update the canonical URLs, `sitemap.xml`, `robots.txt` and `llms.txt`.
